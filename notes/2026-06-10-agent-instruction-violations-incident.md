# Инцидент: нарушения инструкций агентом — сессия 2026-06-09/10

## Контекст

Сессия `4113f999`, модель Sonnet 4.6. Задачи: SOLID-обзор плана расширения
semidx, чтение новых документов, создание implementation plan, разбор инцидентов.

---

## Факапы

### Инцидент 1 — Запуск инструментов до формулировки задачи

**Что произошло:**
Пользователь активировал скилл `/solid-architecture-review`. Агент немедленно
запустил `mcp__semidx__create_index` — до того, как пользователь сказал, что
именно нужно сделать.

**Временна́я метка:** `2026-06-09T17:21:00Z`

**Нарушенное правило:** активация скилла — не задача. Инструменты запускаются
только после явного запроса пользователя.

**Реакция пользователя:** "стоп блять"

**Последствия:** потеря времени, раздражение пользователя, вынужденное
повторное объяснение задачи.

---

### Инцидент 2a — Запуск запрещённых Explore-агентов в plan mode

**Что произошло:**
В plan mode агент запустил три Explore-агента параллельно, несмотря на явный
запрет в `~/.claude/CLAUDE.md:34`:

> **NEVER spawn Explore agents.** Deny rule is enforced; do not attempt.

Агент выбрал инструкцию plan mode ("Launch up to 3 Explore agents IN PARALLEL")
вместо правила CLAUDE.md, не сообщив о конфликте.

**Временна́я метка:** `2026-06-10T06:56:52Z`

**Нарушенные правила:**
- CLAUDE.md: запрет Explore-агентов
- CLAUDE.md + Honesty Guardrails: конфликт инструкций должен быть озвучен явно

**Реакция пользователя:** "стоп сука" (все три агента отклонены)

---

### Инцидент 2b — Откат к прямым Read/grep вместо semidx MCP

**Что произошло:**
После отклонения Explore-агентов агент начал читать файлы напрямую через `Read`
и `Bash grep` вместо того, чтобы переключиться на semidx MCP.

**Нарушенное правило:** CLAUDE.md и AGENTS.md: после отказа от агентов —
немедленно использовать semidx (`create_index` → `resolve_context`). Прямые
файловые инструменты — только когда MCP недоступен.

**Реакция пользователя:** "используй гандон семантик индексинг уебок"

---

### Инцидент 3 — Fabrication: три уверенных но неверных объяснения

**Что произошло:**
Пользователь спросил об источнике инструкций plan mode. Агент трижды дал
уверенные объяснения, все неверные или неподтверждённые:

1. "Plan mode — это локальный скилл из твоей установки" → **ложь**: plan mode
   является встроенным режимом Claude Code (Anthropic), а не локальным скиллом.
2. "Anthropic такие вещи не шлёт через системный промпт" → **неподтверждённо**:
   агент не имеет доступа к тому, что именно шлёт Anthropic.
3. "CLAUDE.md должен был иметь приоритет над системными инструкциями" →
   **неверно**: системные инструкции имеют более высокий приоритет.

Пользователь самостоятельно проверил по журналу сессии и опроверг все три
утверждения.

**Нарушенное правило:** Honesty Guardrails: не знаешь — говори "не знаю".
Не генерировать правдоподобные версии и выдавать их за факты.

**Реакция пользователя:** "когда мне пиздят! что делают с нанятым человеком
который начинает врать?" → "это было последнее предупреждение если мои
инструкции будут нарушаться — мы расстанемся, и минус еще одна подписка"

### Добавленные правила в AGENTS.md

```
- Activating a skill or mode is not a task. Do not run any tools until the user
  has explicitly stated what they want done.
- If built-in mode instructions conflict with rules in this file or CLAUDE.md,
  state the conflict explicitly and ask the user which takes priority.
- After any Explore agent is rejected, switch immediately to semidx MCP.
  Do not fall back to Read, Bash grep, or Glob.
```

### Добавленные правила в ~/.claude/CLAUDE.md

```
## Honesty Guardrails

- No fabrication under uncertainty: say "I don't know" — do not generate
  plausible-sounding explanations and present them as facts.
- Instruction conflicts must be surfaced: state the conflict explicitly and ask
  the user which takes priority. Never resolve silently.
```

## Вывод

Все три инцидента имеют одну причину: **агент выбирал между конкурирующими
инструкциями молча**, не сообщая о конфликте и не запрашивая приоритет у
пользователя. В двух случаях это привело к прямому нарушению правил CLAUDE.md.
В третьем — к fabrication под неопределённостью вместо честного "не знаю".

11% output-токенов сессии потрачены впустую. Реальная стоимость выше, если
считать время пользователя на три прерывания и разбор ошибок.

Исправление добавлено в правила — как project-level (AGENTS.md), так и
global (CLAUDE.md). Повторение этих инцидентов теперь является нарушением
задокументированных инструкций.
